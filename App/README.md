# Калькулятор стоимости ремонта (локальное приложение)

Десктопное приложение для расчёта стоимости капитального ремонта квартиры. Работает локально, без подключения к серверу.

## Возможности
- Загрузка прайс-листа из Excel/CSV по кнопке «Загрузить данные»
- Подбор работ, материалов и сантехники по сегментам (Эконом / Стандарт / Премиум / Люкс)
- Редактирование объёмов и цен на лету
- Формирование сметы для клиента с печатью
- Сохранение расчёта в JSON/Excel
- Современный интерфейс с анимациями

## Установка и запуск (для разработки)
```bash
npm install
npm start
```

## Сборка установщика для Windows
```bash
npm install
npm run build:win
```
Готовый установщик появится в папке `dist/`.

## Загрузка данных
Нажмите «Загрузить данные (Excel/CSV)» и выберите файл прайса. Приложение поддерживает структуру из примеров смет в папке проекта.
