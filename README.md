# 🧮 Калькулятор стоимости ремонта

**Приложение для Windows, которое помогает составить смету на капитальный ремонт квартиры из актуального прайс-листа.**

~~~
Прайс-лист → подбор работ и материалов → расчёт → смета для заказчика
~~~

## 🎯 Какую задачу решает

При подготовке сметы нужно собрать цены на работы, материалы и сантехнику, учесть объёмы и пересчитать бюджет при изменении комплектации. Калькулятор объединяет эти действия в одном интерфейсе. Стоимость каждой выбранной позиции рассчитывается по объёму и цене за единицу. Приложение показывает промежуточные суммы по категориям и общий итог.[Главный экран](images/Снимок экрана (11).png)

Например, если заказчику нужно уложиться в определённый бюджет, можно изменить сегмент отделки, пересмотреть выбранные позиции и сразу увидеть новый итог перед отправкой сметы.

## 👤 Для кого

| Пользователь | Как применяет |
| --- | --- |
| **Сметчик или менеджер ремонтной компании** | Загружает прайс, подбирает позиции под объект и готовит смету для клиента. |
| **Прораб или частный мастер** | Уточняет объёмы, корректирует цены и пересчитывает сумму после обсуждения работ. |
| **Владелец квартиры** | Может оценить предварительный бюджет, если у него есть прайс-лист и известны объёмы работ. |

## 🛠️ Возможности

- Импорт прайс-листа из Excel или CSV по структуре [шаблона](App/src/price_template.xlsx). Приложение читает первый лист файла Excel.
- Отдельные списки работ, материалов и сантехники. Для материалов и сантехники доступны сегменты **Эконом**, **Стандарт**, **Премиум** и **Люкс**.
- Редактирование количества и цены с автоматическим пересчётом.
- Предпросмотр и печать сметы. В расчёт можно внести имя заказчика, телефон, адрес объекта и комментарий.
- Сохранение сметы в **Excel (.xlsx)** или **JSON** через диалог сохранения.

## 🚀 Запуск на Windows

Установите Node.js с npm, затем выполните из корня репозитория.

~~~powershell
cd App
npm ci
npm start
~~~

Для запуска с установкой зависимостей можно также открыть [START.bat](START.bat). Когда приложение откроется, загрузите [шаблон прайса](App/src/price_template.xlsx) с помощью кнопки загрузки файла и отметьте нужные позиции.

### Сборка установщика

После установки зависимостей выполните в папке `App`:

~~~powershell
npm run build:win
~~~

Установщик для Windows x64 появится в `App/dist/`.

## ⚙️ Как устроен проект

- **Electron** открывает окно приложения и предоставляет диалоги выбора и сохранения файлов.
- **HTML, CSS и JavaScript** отвечают за интерфейс, выбор позиций и расчёт сметы.
- **SheetJS** читает таблицы и формирует Excel-файл.
- **electron-builder и NSIS** собирают установщик для Windows.

Загрузка прайса с Яндекс.Диска опциональна. Для неё укажите свою публичную ссылку в константе `YANDEX_PUBLIC_URL` в [app.js](App/src/app.js). Ручной импорт доступен сразу.
